# Customer page preview assets

Northline, Ruang, Ledger & Co., Daily Goods, Aruna, and Karsa are dummy brands.
Their monochrome SVG marks are original code-native illustrations, not logos
of existing companies. The conversion mosaic uses decorative vector avatars
and the same original brand marks; none represents a real customer.

Story names, people, and quotes are sample content. The page identifies the
stories as illustrative and quotes as sample testimonials. Replace them with
verified, consented stories before presenting them as customer proof. Never add
Review or AggregateRating schema for samples.
